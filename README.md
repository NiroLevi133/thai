## איפה הנתונים

הכל יושב ב-`data/trip.json` — **זה מקור האמת**. כל שינוי באפליקציה נשמר לשם אוטומטית
תוך פחות משנייה (המחוון בראש המסך מראה "נשמר"). לפני כל כתיבה נשמר גיבוי ב-`data/trip.bak.json`.

### ייבוא מחדש מהאקסל

המקור הוא גיליון יחיד בשם **"מלונות שהוזמנו"** עם שורה אחת לכל מלון, בעמודות (A→N):
יעד, שם מלון, סוג חדר, צ׳ק-אין, צ׳ק-אאוט, מספר לילות, מחיר ללילה, מחיר כולל, דרך מי
הוזמן, מספר הזמנה, ביטול חינם עד, סטטוס ההזמנה (טקסט חופשי — מסווג אוטומטית לסגור/מועמד/
נפסל), הערות, וקישור למלון (כהיפרלינק על התא). היעדים (המסלול, הסדר, טווח התאריכים)
נגזרים מתוך עמודת "יעד" וטווח התאריכים של המלונות המשויכים אליה — אין גיליון מסלול נפרד.

הדרך הכי נוחה: מסך **הגדרות → ייבוא מאקסל** — מעלים את קובץ ה-.xlsx והאפליקציה מעדכנת
יעדים ומלונות בהתאם. אפשר להשתמש בזה שוב בכל פעם שהאקסל המקורי מתעדכן (הזמנות חדשות,
מחירים וכו').

אפשר גם מהטרמינל, על הקובץ שב-`~/Downloads` (או `TRIP_XLSX=/path/to/file.xlsx npm run import`):

```bash
npm run import     # דורס את data/trip.json מהקובץ המקורי
```

⚠️ שתי הדרכים **מוחקות כל שינוי שעשית באפליקציה** (שולם, קישורים, הערות) ומחליפות אותו
במה שכתוב באקסל. השתמש בזה רק אם אתה רוצה לרענן את הנתונים מהמקור.

הייבוא רץ ב-TypeScript (`server/importExcel.ts`, עם SheetJS), אותו קוד גם בהרצה מקומית
וגם בגרסה שמפורסמת ל-Vercel (`api/import-excel.ts`).

## המסכים

| מסך | מה יש בו |
|---|---|
| **דשבורד** | ספירה לאחור, התראות ממויינות לפי דחיפות, סקירת כל היעדים |
| **מסלול** | תצוגת יעדים עם רצועת לילות (ירוק=מכוסה, אדום=פתוח), ותצוגת יום-יום |
| **מלונות** | סגורים / מועמדים / נפסלו. סימון "שולם", עריכת תאריכים ומחירים, "סגרתי" למועמד |
| **תחבורה** | כל המעברים בין היעדים + טיסות. סוג, מחיר, משך, אסמכתא |
| **אטרקציות** | לפי יעד, עם שיבוץ ליום ספציפי שמופיע מיד בטיימליין |
| **תקציב** | שולם / מחויב / אומדן, גרפים, והוצאות נוספות |
| **הגדרות** | שער באהט, תקציב, מצב כהה/בהיר, וייצוא |

## התראות

הדשבורד מדרג לפי דחיפות:
- 🔴 **אדום** — דדליין ביטול חינם בתוך 7 ימים
- 🟠 **כתום** — בתוך 21 יום, לילות ללא מלון, סתירות בנתונים
- 🔵 **כחול** — הזמנות שלא סומנו כשולמו, תחבורה לא סגורה

## ייצוא

מתוך מסך ההגדרות:
- **אקסל** — גיבוי בשני גיליונות, בפורמט של הקובץ המקורי
- **.ics** — 35 אירועים ליומן: צ׳ק-אין, צ׳ק-אאוט, כל דדליין ביטול, ומעברי תחבורה
- **JSON** — הנתונים הגולמיים
